# PowerScale — Backup & Restore

> Backup configuration, restore procedures, and validation for Dell PowerScale.

## Overview

PowerScale provides several mechanisms for data protection and recovery:

- **SnapshotIQ** — point-in-time directory snapshots for rapid file-level recovery
- **SyncIQ** — asynchronous replication to a remote PowerScale cluster for DR
- **NDMP** — network backup via NetBackup, Veritas, or CommVault
- **Veeam NAS Backup** — NAS backup integration via Veeam v12+

Refer to [Procedures](../procedures/) for snapshot management commands and to [Components](../../architecture/components/) for SyncIQ replication details.
