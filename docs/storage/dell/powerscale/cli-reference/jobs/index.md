# Jobs (Background Tasks)

> Part of the Dell PowerScale (Isilon) CLI Reference.

---

```bash
# List running jobs
isi job status
isi job jobs list
isi job jobs view <job_id>

# Job types
isi job types list
isi job types view <type_name>

# Start / cancel a job
isi job jobs start <type_name>
isi job jobs cancel <job_id>

# Job history
isi job history list
isi job events list
```
