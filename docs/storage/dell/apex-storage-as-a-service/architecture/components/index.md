# APEX Storage as a Service — Components

> Part of the [APEX Storage as a Service](../../) reference.

---

| Component | Role |
|---|---|
| Dell-managed on-premises hardware | PowerStore, PowerScale, or PowerFlex — owned and maintained by Dell |
| APEX Console (console.dell.com) | Customer portal for subscription management, capacity requests, billing, and support |
| APEX REST API | Programmatic access to systems, subscriptions, capacity, performance, and alerts |
| Secure Connect Gateway (SCG) | Forwards telemetry from on-premises hardware to CloudIQ and Dell support back-end |
| CloudIQ | Health scoring, alerting, and capacity forecasting for APEX systems |
| Dell support organisation | Responsible for hardware remediation, firmware upgrades, and field service |
