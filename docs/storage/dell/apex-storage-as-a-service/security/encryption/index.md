# APEX Storage as a Service — Encryption

> Part of the [APEX Storage as a Service](../../) reference.

---

- APEX Console and API access is protected by HTTPS (TLS 1.2+) managed by Dell's cloud infrastructure
- Telemetry from on-premises hardware to CloudIQ is forwarded via SCG over TLS 1.2 or higher
- Data-at-rest encryption on the underlying hardware (PowerStore, PowerScale, PowerFlex) follows each platform's encryption configuration — see the respective platform's security documentation
