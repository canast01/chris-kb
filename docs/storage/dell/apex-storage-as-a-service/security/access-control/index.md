# APEX Storage as a Service — Access Control

> Part of the [APEX Storage as a Service](../../) reference.

---

- Assign APEX Console roles with least-privilege: most operators need read access to dashboards; only administrators need to manage subscriptions or raise service requests
- Use separate API credentials per integration (monitoring, automation, reporting)
- Audit APEX Console user access quarterly and remove stale accounts
- Do not share API credentials between teams or integrations
