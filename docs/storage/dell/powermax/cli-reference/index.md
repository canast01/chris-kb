# Dell PowerMax CLI Reference (SYMCLI)

Commonly used Solutions Enabler (SYMCLI) commands for managing Dell PowerMax and VMAX arrays.

> All commands require `-sid <SymmID>` to target a specific array. Run `symcfg list` first to identify the SID.

<div class="kb-grid kb-grid-3">

<a class="kb-card" href="discovery/">
  <strong>Discovery & Array Info</strong>
  <span>symcfg list/discover/show, directors, ports, cache, and pools.</span>
</a>

<a class="kb-card" href="devices/">
  <strong>Devices</strong>
  <span>symdev list (assigned/unassigned/mapped/failed/tdev) and device performance.</span>
</a>

<a class="kb-card" href="storage-groups/">
  <strong>Storage Groups</strong>
  <span>symsg list/show/create/delete, add/remove devices, and child SGs.</span>
</a>

<a class="kb-card" href="masking-views/">
  <strong>Masking Views & Access</strong>
  <span>symaccess views, initiator groups, and port groups.</span>
</a>

<a class="kb-card" href="ports/">
  <strong>Ports & Hardware</strong>
  <span>symport list/show, FC login info, and physical disk management.</span>
</a>

<a class="kb-card" href="srdf/">
  <strong>SRDF — Replication</strong>
  <span>SRDF group query, establish, split, suspend, resume, failover, and failback.</span>
</a>

<a class="kb-card" href="snapvx/">
  <strong>SnapVX — Snapshots</strong>
  <span>SnapVX list/create/link/unlink/restore/terminate and rename.</span>
</a>

<a class="kb-card" href="performance/">
  <strong>Performance & Statistics</strong>
  <span>symstat by SG, device, director, backend, cache, and port.</span>
</a>

<a class="kb-card" href="events/">
  <strong>Events & Audit</strong>
  <span>symevent and symaudit list with time range and user filters.</span>
</a>

<a class="kb-card" href="device-groups/">
  <strong>Device Groups (Legacy)</strong>
  <span>symdg list/show/create/delete and device add/remove (legacy scripting).</span>
</a>

</div>
