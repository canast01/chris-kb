# FOD — Components

> Part of the [Flex on Demand](../../) reference.

---

| Component | Role |
|---|---|
| PowerMax / PowerStore / PowerScale array | On-premises hardware with pre-installed burst capacity |
| HYPERMAX OS / PowerStore OS / OneFS | Array operating system that tracks metered capacity |
| Unisphere / PowerStore Manager | Management UI and REST API for capacity visibility |
| SYMCLI / Solutions Enabler | Command-line interface for SYMCLI-managed arrays (PowerMax) |
| Secure Connect Gateway (SCG) | Forwards metered usage telemetry to Dell CloudIQ |
| CloudIQ | Aggregates capacity telemetry; drives monthly billing metering |
| Dell APEX Console | Billing and subscription management portal |
| Dell License Management Portal | Source of license files for base and burst tier entitlements |
