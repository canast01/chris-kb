# FOD — Encryption

> Part of the [Flex on Demand](../../) reference.

---

FOD metering telemetry is transmitted from the array to CloudIQ via the Secure Connect Gateway over TLS 1.2 or higher. The telemetry payload contains capacity metrics only — no user data, file contents, or host data is transmitted.

APEX Console access is protected by HTTPS (TLS 1.2+) managed by Dell's cloud infrastructure.
