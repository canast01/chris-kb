# Pure Storage CLI Reference

Commonly used Purity CLI commands for managing Pure FlashArray systems.

<div class="kb-grid kb-grid-3">

<a class="kb-card" href="array/">
  <strong>Array & System Management</strong>
  <span>purearray list, monitor (latency/bandwidth/iops), setattr, upgrade, and phonehome.</span>
</a>

<a class="kb-card" href="admin/">
  <strong>Admin Accounts</strong>
  <span>pureadmin create/delete/list, API tokens, lockouts, and global settings.</span>
</a>

<a class="kb-card" href="alerts-audit/">
  <strong>Alerts & Audit</strong>
  <span>purealert list/flag/acknowledge and pureaudit list with filters.</span>
</a>

<a class="kb-card" href="config/">
  <strong>Configuration & Directory Services</strong>
  <span>pureconfig list, pureds check, puredns show/setattr for DNS config.</span>
</a>

<a class="kb-card" href="hardware/">
  <strong>Drives & Hardware</strong>
  <span>puredrive list/admit and purehw list by type (bay, fc, eth, fan, psu).</span>
</a>

<a class="kb-card" href="hosts/">
  <strong>Hosts & Host Groups</strong>
  <span>purehgroup and purehost create/delete/rename, connect/disconnect volumes, WWNs, iQNs.</span>
</a>

<a class="kb-card" href="network-ports/">
  <strong>Network & Ports</strong>
  <span>purenetwork list and pureport list by type (fc, eth) with initiator info.</span>
</a>

<a class="kb-card" href="pods/">
  <strong>Pods (ActiveCluster)</strong>
  <span>purepod create/destroy/recover/demote, stretch, replica links.</span>
</a>

<a class="kb-card" href="volumes/">
  <strong>Volumes & Snapshots</strong>
  <span>purevol create/destroy/recover/list/connect/copy/snap/monitor.</span>
</a>

<a class="kb-card" href="csv-exports/">
  <strong>CSV Exports</strong>
  <span>Export array, volumes, hosts, hardware, admin, and alerts data to CSV.</span>
</a>

</div>
