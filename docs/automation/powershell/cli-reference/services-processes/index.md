# Services & Processes

> Part of the PowerShell CLI Reference.

---

```powershell
# Services
Get-Service
Get-Service -Name <name>
Start-Service <name>
Stop-Service <name>
Restart-Service <name>
Set-Service -Name <name> -StartupType Automatic

# Processes
Get-Process
Get-Process -Name <name>
Stop-Process -Name <name>
Stop-Process -Id <pid> -Force
```
