# External Connectivity

## Overview

External connectivity allows infrastructure systems to communicate with cloud services, partners, and remote sites.

## Daily Checks

- Verify outbound connectivity
- Check firewall rules
- Confirm DNS resolution
- Review latency metrics

## Health Commands

```bash
ping external-host
traceroute external-host
curl https://example.com
```

## Troubleshooting Workflow

1. Confirm network route
2. Validate firewall policies
3. Check DNS configuration
4. Review security controls
