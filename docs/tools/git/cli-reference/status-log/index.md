# Status & Log

> Part of the Git CLI Reference.

---

```bash
git status
git diff
git diff --staged
git diff <branch1>..<branch2>

git log
git log --oneline
git log --oneline --graph --all
git log -p                      # With diffs
git log --author="name"
git log --since="2 weeks ago"
git log --follow <file>
git show <commit>
```
