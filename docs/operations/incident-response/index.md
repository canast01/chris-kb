# Incident Response

## Overview

Incident response is the process of detecting, triaging, resolving, and documenting service-impacting events.

## Triage Checklist

- Confirm affected service
- Identify business impact
- Check recent changes
- Review monitoring alerts
- Assign owner

## Response Workflow

1. Detect issue
2. Confirm impact
3. Stabilize service
4. Identify root cause
5. Document RCA and follow-up actions
