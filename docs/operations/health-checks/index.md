# Health Checks

## Overview

Health checks provide repeatable validation of infrastructure platforms before, during, and after operational changes.

## Standard Checklist

- Alerts reviewed
- Capacity reviewed
- Performance reviewed
- Replication reviewed
- Backup reviewed
- Logs reviewed
- Certificates reviewed

## Workflow

1. Run platform-specific checks
2. Document findings
3. Assign remediation items
4. Re-check after fixes
5. Save results for audit history
