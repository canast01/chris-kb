# Virtualization — Exam Tracking

<div class="kb-summary">
VMware certification exam tracking — scheduled exams, attempt history, scores, and renewal deadlines for VCP, VCAP, and VCDX tracks.
</div>

```text
┌───────────────────────────────── VMware Certification Track Overview ─────────────────────────────────┐
│                                                                                                       │
│   Track progression: VCP (Associate) → VCAP (Professional) → VCDX (Design Expert)                     │
│   All certs are product-track-specific: DCV, NV, CMA, DTM, SEC                                        │
│   All certifications expire after 2 years; recertify by passing current or higher exam                │
│                                                                                                       │
│   VCP — VMware Certified Professional                                                                 │
│   Exam prefix: 2V0-xx.xx / 70 questions / 135 min / pass score 300 of 500                             │
│   Prerequisite: must complete official VMware training course before sitting the exam                 │
│   Recertification: retake the current VCP exam or pass a VCAP within the 2-year window                │
│                                                                                                       │
│   VCAP — VMware Certified Advanced Professional                                                       │
│   Exam prefix: 3V0-xx.xx / two streams per track                                                      │
│   Deploy stream: hands-on lab exam; perform tasks in a live vSphere environment                       │
│   Design stream: case study exam; analyse requirements and justify architectural decisions            │
│                                                                                                       │
│   VCDX — VMware Certified Design Expert                                                               │
│   Exam prefix: 4V0-xx.xx / highest VMware certification                                               │
│   Requires: design portfolio submission → written defence → panel presentation                        │
│                                                                                                       │
│   Tracks: DCV = Data Center Virtualisation (vSphere/vSAN/NSX)                                         │
│            NV = Network Virtualisation (NSX)   CMA = Cloud Mgmt & Automation                          │
│           DTM = Desktop & Mobility (Horizon)   SEC = Security                                         │
│                                                                                                       │
│   Key terms:                                                                                          │
│   VCP       = entry-level cert; training course prerequisite required before exam                     │
│   VCAP      = advanced professional; Deploy (hands-on) or Design (case study) stream                  │
│   VCDX      = design expert; portfolio submission and panel defence required                          │
│   DCV       = Data Center Virtualization track; most common path for infra engineers                  │
│   Pearson VUE = exam delivery platform; schedule online at least 5 business days ahead                │
│   Acclaim   = Credly-powered badge platform; VMware digital badges issued here on pass                │
└───────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
