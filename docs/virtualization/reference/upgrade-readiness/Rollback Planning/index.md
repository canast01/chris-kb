# Rollback Planning

Rollback depends on the product being upgraded. Some upgrades cannot be easily rolled back without restore or redeploy.

## Rollback Planning Should Include

- vCenter file-based backup
- Snapshot guidance if supported
- ESXi bootbank rollback option
- VxRail support guidance
- NSX backup
- Aria product backup
- Database backup if applicable
- Clear go/no-go decision point
- Vendor escalation path
