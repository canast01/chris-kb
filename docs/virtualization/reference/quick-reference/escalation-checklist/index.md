# Virtualization Escalation Checklist

Before escalation, collect:

```
┌──────────────────────────────────────────────────────────────────────┐
│                    Escalation Package                                │
├─────────────────────────────┬────────────────────────────────────────┤
│  Collect Before Escalating  │  Include in Escalation Message         │
├─────────────────────────────┼────────────────────────────────────────┤
│ ☐ Host / VM / Cluster name  │  Scope: what is affected               │
│ ☐ Timestamp + timezone      │  Impact: users/apps down/degraded      │
│ ☐ Screenshots of alerts     │  Timeline: when started, what changed  │
│ ☐ Exact error messages      │  Evidence: logs, screenshots, commands │
│ ☐ Recent changes            │  Next action: what you need from them  │
│ ☐ Log snippets              │                                        │
│ ☐ Support bundle (if VMware)│                                        │
└─────────────────────────────┴────────────────────────────────────────┘
```

- Host name
- VM name
- Cluster name
- Datastore name
- Timestamp
- Timezone
- Screenshot of alerts
- Recent changes
- Error message
- Log snippet
- Impact description
- Current status

Escalation should include:

Scope  
Impact  
Timeline  
Evidence  
Next action
