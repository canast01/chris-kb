# Common Datastore Issues

| Symptom | What to Check |
|---|---|
| Datastore full | Snapshots, ISO files, orphaned VMDKs, old templates |
| High latency | Array performance, queue depth, paths, congestion |
| Datastore inaccessible | SAN zoning, LUN masking, paths, storage controller |
| VMFS issue | Locks, resignature, extent health |
| vSAN object warning | Storage policy, resync, disk group, capacity |
