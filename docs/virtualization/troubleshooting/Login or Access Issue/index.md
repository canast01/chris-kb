# Common Login Issues

| Symptom | What to Check |
|---|---|
| Cannot log into vCenter | SSO service, identity source, locked account |
| AD users cannot log in | LDAP/LDAPS, domain controller, DNS, time sync |
| Local admin works but AD does not | Identity source or AD connectivity |
| Permission denied | vCenter role assignment, group membership |
| Session timeout | Browser cache, SSO token, service health |
