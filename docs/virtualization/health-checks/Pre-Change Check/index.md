# Pre-Change Checks

Pre-change checks confirm the platform is healthy before maintenance begins.

- Confirm vCenter access
- Confirm ESXi host connectivity
- Check active alarms
- Confirm no unexpected host maintenance mode
- Check datastore free space
- Confirm no stuck snapshots
- Confirm backup status
- Check vSAN health if applicable
- Confirm NTP and DNS health
- Confirm rollback plan
- Capture current versions
- Confirm maintenance window approval
