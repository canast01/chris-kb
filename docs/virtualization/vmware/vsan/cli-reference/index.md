# vSAN CLI Reference

Commonly used ESXi shell and PowerCLI commands for managing and troubleshooting vSAN clusters.

<div class="kb-grid kb-grid-3">

<a class="kb-card" href="cluster-status/">

</a>

  <strong>Health & Diagnostics</strong>
  <span>esxcli vsan health cluster/summary get, trace, debug objects, and resync.</span>
</a>

<a class="kb-card" href="disk-groups/">
  <strong>Disk Groups</strong>
  <span>esxcli vsan storage list/stats/evacuate/add/remove for disk groups.</span>
</a>

</a>

<a class="kb-card" href="powercli/">

  <span>Get-VsanClusterConfiguration, Test-VsanClusterHealth, disk groups, object health, resync, and capacity.</span>

<a class="kb-card" href="rvc/">
