# Healthy State Reference


<div class="kb-summary">
Healthy State Reference reference covering Cluster, Storage, Network, VMs, Management.

*Applies to: vSphere 7.x / 8.x*
</div>
![Healthy State Reference](../../../../assets/virtualization-vmware-reference-quick-reference-healthy-stat.svg)




## Cluster

All hosts connected  
No alarms  
Capacity healthy  

## Storage

Latency < 10 ms  
No failed paths  
No resync backlog  

## Network

No packet loss  
All uplinks up  

## VMs

No consolidation warnings  
No swap  
CPU ready low  

## Management

vCenter reachable  
Services running  
Backups successful
