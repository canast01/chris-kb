# Virtualization — Review Plan

<div class="kb-summary">
VMware certification study plan — weekly review schedule, topic weighting by exam blueprint, and milestone checkpoints before exam date.
</div>

```text
┌────────────────────────────────── VCP-DCV Study Plan — 6-Week Cycle ──────────────────────────────────┐
│                                                                                                       │
│   Weight study time by blueprint section weighting: Architecture is the largest section               │
│   Practice exam score ≥75% before booking; raw pass threshold is approximately 65–70%                 │
│   Final week: exam guide review, weak-area drills, and sample questions only — no new topics          │
│                                                                                                       │
│   Week 1 — Architecture & Storage                                                                     │
│   ESXi and vCenter architecture, VMkernel, VMCA                                                       │
│   vSAN disk groups, fault domains, FTT, storage policies                                              │
│   Storage protocols: NFS, iSCSI, FC, VAAI, VASA, SPBM, vVOLs                                          │
│                                                                                                       │
│   Week 2 — Networking & Security                                                                      │
│   VSS vs VDS comparison, PVLAN types (Isolated/Community/Promiscuous)                                 │
│   NIOC traffic types and bandwidth shares; NSX DFW and Edge gateway                                   │
│   VM Encryption, vSphere Trust Authority, vTPM, VBS                                                   │
│                                                                                                       │
│   Week 3 — Cluster Services                                                                           │
│   HA admission control options (percentage, slot-based, failover hosts)                               │
│   DRS automation levels, affinity/anti-affinity rules, EVC mode                                       │
│   FT requirements and limits, vCLS agent VMs, retreat mode impact                                     │
│                                                                                                       │
│   Week 4 — Lifecycle & Administration                                                                 │
│   vLCM: image-based vs baseline-based (mutually exclusive per cluster)                                │
│   Host Profiles, answer files, Auto Deploy, Content Library                                           │
│   Resource pools: shares, reservations, limits, expandable reservations                               │
│                                                                                                       │
│   Week 5 — Monitoring & Troubleshooting                                                               │
│   ESXTOP metrics: %RDY (CPU), DAVG (storage), memory balloon/swap order                               │
│   Log files: vmkernel.log, vpxd.log, fdm.log, hostd.log, vpxa.log                                     │
│   vCLS retreat mode, Skyline telemetry, vCenter performance charts                                    │
│                                                                                                       │
│   Week 6 — Mock Exams × 3                                                                             │
│   Full 70-question timed run; score gap analysis; targeted weak-area drills                           │
│   Book exam when three consecutive mock runs score ≥75%                                               │
│                                                                                                       │
│   Key terms:                                                                                          │
│   Blueprint = official exam guide with objective weights per section; download from Broadcom          │
│   OSI       = On-Screen Items (VCAP-Deploy); hands-on tasks in a live lab under time pressure         │
│   Mock exam = MeasureUp / Udemy practice packs; different question pool from the real exam            │
└───────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
