# Virtualization — Certifications

<div class="kb-summary">
VMware certification study notes — exam tracking, weak areas, and review plans.

*Applies to: vSphere 7.x / 8.x*
</div>

```text
┌────────────────────────────────── VMware Certification — Study Hub ───────────────────────────────────┐
│                                                                                                       │
│   Track progression: VCP (Associate) → VCAP (Professional) → VCDX (Design Expert)                     │
│   Primary track for infra engineers: DCV — covers vSphere, vSAN, NSX, VCF                             │
│   All certifications expire after 2 years; training course required before first VCP attempt          │
│                                                                                                       │
│   Exam Tracking                                                                                       │
│   Scheduled exams, attempt history, pass/fail scores, renewal deadlines                               │
│   Track all certs in one place: code, attempt date, score, expiry date                                │
│                                                                                                       │
│   Review Plan                                                                                         │
│   6-week study cycle with topic weighting by exam blueprint section                                   │
│   Mock exam milestones: aim for ≥75% before booking; book when 3 consecutive runs pass                │
│                                                                                                       │
│   Practice Notes                                                                                      │
│   Question type patterns: single-answer, multiple-answer, long-stem scenario                          │
│   Elimination strategy for scenario questions; timing tips (2 min/question)                           │
│                                                                                                       │
│   Weak Areas                                                                                          │
│   Flag sub-topics where score drops below 75% across two or more practice runs                        │
│   Study in isolation; re-test before returning to full mixed practice exams                           │
│                                                                                                       │
│   Key terms:                                                                                          │
│   VCP       = VMware Certified Professional; entry-level; training course prerequisite required       │
│   VCAP      = VMware Certified Advanced Professional; Deploy (hands-on) or Design (case study)        │
│   DCV       = Data Center Virtualization track; most common VMware cert path for infra engineers      │
│   Blueprint = official exam guide with section weights; download from Broadcom education portal       │
└───────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
