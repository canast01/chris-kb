# VMware Licensing

<div class="kb-summary">
VMware licensing reference covering the post-Broadcom edition structure, subscription model, per-core pricing, and the key differences between vSphere Foundation, VCF, and the add-on bundles. Includes migration considerations from legacy perpetual licences.
</div>

```text
┌───────────────────────────────────── VMware — Licensing ──────────────────────────────────────────────┐
│                                                                                                       │
│  OVERVIEW                                                                                             │
│  Broadcom restructured VMware licensing in 2024 — perpetual licences ended; subscription only         │
│  Two main platforms: vSphere Foundation (VVF) and VMware Cloud Foundation (VCF)                       │
│  Pricing: per core, sold in packs; minimum 16 cores per CPU socket                                    │
│                                                                                                       │
│  EDITIONS                                                                                             │
│  vSphere Foundation: vSphere Enterprise Plus + vSAN + Aria                                            │
│  VMware Cloud Foundation: full SDDC — adds NSX, SDDC Manager, Tanzu                                   │
│  Add-on SKUs: HCX, Horizon, SRM/vR, advanced security, observability packs                            │
│                                                                                                       │
└───────────────────────────────────────────────────────────────────────────────────────────────────────┘
```
