# DRS and vMotion Behavior

## DRS Modes

Manual  
Partially automated  
Fully automated

## vMotion Requirements

Shared storage or vSAN  
Network reachability  
CPU compatibility  
No locked resources

## Common Failure Causes

Network latency  
Storage latency  
CPU compatibility mismatch  
Host resource contention

## Validation

Migration completes successfully  
No task failure  
VM performance stable
