# Maintenance Risk Validation

## Before Maintenance

Check:

- Cluster capacity
- vSAN health
- Storage latency
- Network stability
- Active resync
- Backup status

## Red Flags

Do NOT proceed if:

- Resync in progress
- Capacity below threshold
- Host hardware alerts
- Network instability
- Unresolved alarms

## Safe State

Maintenance is safe when:

- No active resync
- Capacity healthy
- Cluster stable
- Monitoring normal
