# NSX Manager — System

> Part of the [NSX-T CLI Reference](../).

---

## NSX Manager — System

```bash
# System status
get managers
get clusters
get services
get service http
get service manager

# Version
get version

# Nodes
get nodes
get node interfaces
get node interface eth0

# Appliance management
set appliance gw-route <prefix> <gw>
set appliance ui <start|stop>
```
