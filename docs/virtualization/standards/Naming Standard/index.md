| ESXi Host | esx-prod-01 |
| Datastore | ds-prod-vsan-01 |
| Port Group | pg-prod-app-vlan100 |
| VM | appname-prod-01 |
| Template | tmpl-win2022-standard |
| Folder | Prod / Dev / Test / Infra |
