## Common Issues

- Adapter collection failure.
- Credential or endpoint issue.
- Alert noise.
- Stale dashboard data.
- Certificate issue.
- Failed workflow.
- Upgrade or lifecycle task failure.

## Operational Tasks

- Review alerts and dashboards.
- Validate collection status.
- Confirm integrations.
- Tune alert policies.
- Review capacity and performance views.
- Document changes.

## Upgrade Notes

- Confirm product compatibility.
- Review release notes.
- Validate certificates and integrations.
- Confirm backup or snapshot position.
- Run post-upgrade collection checks.

## Best Practices

- Keep dashboards simple.
- Tune alerts for action, not noise.
- Keep endpoint ownership clear.
- Document credential dependencies.
- Review collection health regularly.
