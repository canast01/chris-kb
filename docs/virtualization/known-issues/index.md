# Known Issues and Fix Patterns

## Host Disconnected

Cause:

- Network issue
- DNS issue
- Host service failure

Fix:

- Verify management network
- Restart management agents
- Validate DNS resolution

---

## vSAN Capacity Warning

Cause:

- Low free capacity
- Large resync operation

Fix:

- Review capacity
- Delay maintenance
- Add capacity if required

---

## vCenter Login Failure

Cause:

- SSO issue
- Certificate issue

Fix:

- Check SSO services
- Validate certificates
- Review authentication logs
