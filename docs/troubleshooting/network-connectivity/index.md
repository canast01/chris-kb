# Network Connectivity Troubleshooting

## Overview

Network connectivity failures prevent systems from communicating across services, storage, and cloud environments.

## Symptoms

- Unable to reach server
- Packet loss
- Application connection failure
- Timeout errors

## Health Commands

```bash
ping host
traceroute host
ip addr
ip route
```

## Troubleshooting Workflow

1. Confirm IP configuration
2. Validate gateway connectivity
3. Check routing tables
4. Review firewall rules
5. Validate DNS resolution
