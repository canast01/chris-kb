## Overview

Naming conventions provide consistent identification of systems, applications, and infrastructure components.

## Standard Format

ENV-ROLE-SITE-NUMBER

Example:

PRD-DB-NYC-01

## Guidelines

- Use consistent prefixes
- Avoid special characters
- Keep names readable
- Document exceptions
