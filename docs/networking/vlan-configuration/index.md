# VLAN Configuration

## Overview

This procedure defines how to configure VLANs on network infrastructure.

## Pre-Checks

- Confirm VLAN ID
- Confirm network segment requirements
- Verify switch configuration access

## Commands

```bash
show vlan
show interface trunk
configure terminal
```

## Validation

1. Confirm VLAN created
2. Confirm devices assigned to VLAN
3. Validate connectivity
