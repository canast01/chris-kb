# Subnetting

## Overview

Subnetting divides IP networks into smaller address ranges. It is used for routing, segmentation, security boundaries, and capacity planning.

## Daily Checks

- Confirm available IP capacity
- Validate subnet masks
- Review overlapping networks
- Confirm reserved addresses

## Useful Commands

```bash
ipcalc 10.10.10.0/24
ip addr
ip route
nslookup hostname
```

## Troubleshooting Workflow

1. Confirm IP address
2. Confirm subnet mask or CIDR
3. Confirm default gateway
4. Check for overlapping routes
5. Validate reachability
