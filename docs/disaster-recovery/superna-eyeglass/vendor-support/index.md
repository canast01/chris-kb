# Superna Eyeglass Vendor Support

Superna support cases are raised via the Superna support portal at support.superna.net. Before opening an SR, collect a support bundle from the Eyeglass admin UI (Admin > Support Bundle) — this captures logs, configuration, and system state in a single archive. Include the Eyeglass version, OneFS version, SyncIQ policy count, and a description of the error with timestamps.

License validation issues (appliance reporting unlicensed state) are handled separately via the Superna licensing portal — confirm the license file matches the appliance UUID before contacting support.

| Item | Detail |
|---|---|
| Support portal | https://support.superna.net |
| Support bundle | Eyeglass Admin UI → Admin → Support Bundle |
| Required info for SR | Eyeglass version, OneFS version, SyncIQ policy count, error + timestamp |
| License validation | Confirm license UUID matches appliance; re-import if needed |
| Escalation | Request Tier 2 in the portal if initial response does not resolve within SLA |
