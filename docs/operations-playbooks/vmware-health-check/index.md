# VMware Health Check

<div class="kb-note">
Use this for VMware cluster, host, datastore, and VM health reviews.
</div>

## Checks

- [ ] vCenter reachable
- [ ] Clusters healthy
- [ ] Hosts connected
- [ ] No host hardware alarms
- [ ] Datastore capacity is healthy
- [ ] vSAN health is normal if applicable
- [ ] DRS/HA status reviewed
- [ ] Snapshots reviewed
- [ ] VMware Tools status reviewed
- [ ] Backup integration reviewed
