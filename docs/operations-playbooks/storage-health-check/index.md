## Checks

- [ ] Array/system health is normal
- [ ] No failed disks or degraded components
- [ ] Capacity is within threshold
- [ ] Replication is healthy
- [ ] Snapshots are running as expected
- [ ] Support connectivity is healthy
- [ ] Firmware/code level is documented
- [ ] Alerts are reviewed and assigned
