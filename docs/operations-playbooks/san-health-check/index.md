# SAN Health Check

<div class="kb-note">
Use this for Cisco and Brocade SAN fabric reviews.
</div>

## Checks

- [ ] Switch status is healthy
- [ ] ISLs are online
- [ ] No port errors above normal baseline
- [ ] No unexpected offline ports
- [ ] Zoning changes are documented
- [ ] Principal switch / fabric status is normal
- [ ] Firmware level is documented
- [ ] Management platform is reachable

## Common follow-up

- Clear stale alerts only after confirming root cause
- Track recurring CRC/errors
- Confirm host/storage multipathing before any SAN work
