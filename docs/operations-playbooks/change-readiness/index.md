# Change Readiness

<div class="kb-note">
Use this before infrastructure changes.
</div>

## Pre-change checks

- [ ] Scope is clear
- [ ] Risk is understood
- [ ] Backout plan is documented
- [ ] Validation plan is documented
- [ ] Stakeholders notified
- [ ] Maintenance window approved
- [ ] Backup or snapshot confirmed where needed
- [ ] Monitoring checked before start
