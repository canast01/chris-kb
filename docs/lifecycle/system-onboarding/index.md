# System Onboarding Procedure

## Overview

This procedure defines steps to bring a new system into production management.

## Required Steps

- Assign hostname
- Configure IP address
- Join domain or directory
- Install monitoring agent
- Configure backup
- Apply security baseline

## Validation Commands

```bash
hostname
ip addr
ping monitoring-server
```

## Completion Criteria

- System visible in monitoring
- Backup job successful
- Security policies applied
