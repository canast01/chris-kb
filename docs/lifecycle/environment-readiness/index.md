# Environment Readiness Checklist

## Overview

This checklist validates that infrastructure is ready to host new applications or workloads.

## Readiness Checks

- Capacity available
- Network connectivity confirmed
- Storage provisioned
- Monitoring configured
- Backup configured
- Security policies applied

## Validation Commands

```bash
df -h
ping application-server
netstat -rn
```

## Completion Criteria

- Infrastructure validated
- Monitoring operational
- Backup verified
