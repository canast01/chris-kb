# CloudIQ Lifecycle

CloudIQ is a SaaS platform — Dell manages all updates and there is no customer-managed version to maintain. The Secure Connect Gateway (SCG) virtual appliance does have a version lifecycle and must be kept current for compatibility with new Dell platforms and CloudIQ features. SCG upgrades are performed in-place via the SCG admin UI.

| Item | Detail |
|---|---|
| CloudIQ platform | SaaS (Dell-managed, no customer upgrade required) |
| SCG versioning | Customer-managed; check Dell compatibility matrix |
| SCG upgrade method | In-place via SCG admin UI |
| Platform firmware compatibility | Check CloudIQ release notes for new platform support |
| CloudIQ API lifecycle | Versioned; deprecated endpoints published in release notes |
