# Dell AIOps Operations

Daily operations focus on reviewing the AIOps recommendations dashboard for new Critical or High-priority recommendations and checking the active anomaly alerts panel for newly detected anomalies requiring investigation. Monitor infrastructure health score trends across the storage estate to identify systems with declining health scores before they generate incidents. Weekly, review all AI-generated capacity recommendations and action or defer any High-priority items in the recommendation queue, documenting the rationale for any deferrals.

**Daily Checklist**
- AIOps Recommendations dashboard — review new Critical and High recommendations
- Active Anomaly Alerts — investigate newly detected anomalies
- Infrastructure health scores — flag systems with declining trends

**Weekly Tasks**
- Review full recommendation queue — action High-priority items
- Document deferrals with rationale in ITSM
- Confirm all storage systems are reporting (check SCG collection status)
- Review capacity trend charts for systems approaching thresholds
