# Dell AIOps Lifecycle

Dell AIOps is a SaaS platform — feature updates and AI model improvements are deployed by Dell without customer action. Customers should monitor Dell CloudIQ release notes for new features, model updates, and breaking API changes. SCG compatibility with CloudIQ is version-controlled; SCG updates are managed by Dell and pushed automatically where configured, or manually downloaded from the Dell support portal. New AI model rollouts are communicated via Dell's platform update notes in the CloudIQ portal. The primary customer lifecycle action is keeping the SCG current and ensuring newly deployed storage systems are registered and collecting.

| Activity | Responsibility |
|---|---|
| Platform updates | Dell (SaaS — automatic) |
| AI model rollouts | Dell (published in CloudIQ release notes) |
| SCG updates | Dell-pushed or manual download from support portal |
| New system onboarding | Customer (register in CloudIQ, verify SCG collection) |
| Feature availability | Check CloudIQ release notes |
