# Aria Operations — Integrations

<div class="kb-summary">
Adapter-based integration model: each source system connects via a Management Pack adapter running on the analytics cluster or a Remote Collector. Native adapters cover vSphere, NSX, vSAN, and storage; third-party MPs extend to public cloud, network, and ITSM.
</div>

│  Physical Infrastructure:                                                                             │
│  Adapters run on Aria Ops nodes · MPs installed via VMware Marketplace or vendor portal               │
│                                                                                                       │
│  Key terms:                                                                                           │
│                                                                                                       │
│  Management Pack   = Vendor-supplied adapter bundle extending Aria Ops to a new data source           │
│  OOTB adapter      = Out-of-the-box adapter bundled with Aria Operations installation                 │
│  Service account   = Dedicated read-only account used by adapter to authenticate to source            │
│  Outbound plugin   = Connector sending alert/event data from Aria Ops to ITSM or notify               │
│  REST notification = HTTP POST to a webhook URL when an Aria Ops alert fires                          │
│  vCenter SSO       = Single Sign-On; Aria Ops uses vCenter SSO for user authentication                │
│  LDAP/AD           = Directory authentication for Aria Ops local users                                │
│  ServiceNow plugin = Aria Ops plugin creating incidents or changes in ServiceNow on alert             │
│  Log Insight fwd   = Plugin forwarding Aria Ops events to Aria Log Insight for correlation            │
│  SNMP trap         = SNMPv2/v3 trap generated by Aria Ops and sent to an NMS                          │
│  VMware Marketplace= Online portal for downloading Management Packs for Aria products                 │
│  Certificate auth  = TLS client certificate used instead of username/password for adapters            │
│                                                                                                       │
└───────────────────────────────────────────────────────────────────────────────────────────────────────┘
