# Aria Operations Vendor Support

Aria Operations support is provided by Broadcom via the Broadcom Support Portal (support.broadcom.com). When opening a Support Request (SR), collect a support bundle first via Admin > Support > Collect Support Bundle — this includes logs, configuration, and diagnostics. For management pack issues, the VMware Aria Operations community forums are a useful first resource before raising an SR.

**Information to collect before opening an SR**

- Aria Operations version and build number
- Cluster size (number of analytics nodes, data nodes, remote collectors)
- Number of VMs and objects monitored
- Adapter version(s) affected
- Alert or error details with timestamps
- Support bundle from Admin > Support > Collect Support Bundle
