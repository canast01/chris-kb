## Exam Scheduling

- Schedule via Pearson VUE (pearsonvue.com/aws) or AWS Certification portal (aws.training)
- Reschedule/cancel with no penalty if done >24 hours before exam time
- Retake policy: first retake after 14 days; second and subsequent retakes after 14 days each
- Exam results available immediately for most exams (preliminary); official within 5 business days
- Score validity: certifications valid for 3 years; recertify by passing the current version

## Retake and Recertification Notes

- **Retake**: No fee waiver; full exam fee applies each attempt
- **Recertification**: Pass current exam version, or earn a higher-level cert in the same track
- **Exam beta**: Register for beta exams at ~$75 to help AWS calibrate — results take ~3 months
- **Disability accommodations**: Request via Pearson VUE at least 14 days before exam

## Study Checklist

- [ ] Confirm target exam and schedule date in calendar
- [ ] Log current knowledge baseline with a diagnostic practice exam
- [ ] Track domain-level scores on each practice attempt
- [ ] Identify score trend over successive practice attempts
- [ ] Schedule retake within 14 days if needed
- [ ] Note any question topics that repeatedly appear as weak
- [ ] Verify exam code version is current before booking (e.g., SAA-C03 not SAA-C02)
