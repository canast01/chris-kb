# Performance Baselining

## Overview

Performance baselining establishes normal system behavior to detect anomalies.

## Metrics

- CPU utilization
- Memory usage
- Disk latency
- Network latency

## Daily Checks

- Compare metrics to baseline
- Identify performance deviations
- Review alert thresholds

## Workflow

1. Capture normal performance metrics
2. Store baseline values
3. Monitor ongoing performance
4. Investigate anomalies
