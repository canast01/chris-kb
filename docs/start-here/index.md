# Start Here

This KB is built for practical infrastructure work.

Use it when you need quick notes, runbooks, checks, standards, commands, or troubleshooting paths.

## Main workflow

1. Start with the major area.
2. Open the vendor, platform, or service.
3. Use the deeper cards for health checks, troubleshooting, commands, and validation.
4. Add real field notes as issues come up.
